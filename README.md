# DevBoard Assignment

A responsive task-management dashboard built with HTML, CSS and JavaScript DOM manipulation.

## Features

- Six responsive task cards
- Assigned and completed task counters
- Working task completion buttons
- Dynamic activity log with timestamps
- Clear History button
- Background colour theme button
- Current date display
- Blog page containing the five required DOM answers

## Run locally

Open `index.html` in a browser. No installation or build command is required.

## Deploy with GitHub Pages

1. Upload all files to a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then click **Save**.
